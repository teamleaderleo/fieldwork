# Fieldwork — live routing

## In simple words

Fieldwork changes too quickly for a manually copied status page to remain trustworthy. This file therefore contains no card inventory, source head, workflow result, or claimed current count.

Use the live GitHub desks:

- [Human Review Desk #387](https://github.com/teamleaderleo/fieldwork/issues/387) — every technically ready decision for the repository owner, with the suggested review order;
- [Peer Review Queue #213](https://github.com/teamleaderleo/fieldwork/issues/213) — exact assistant and independent technical-review work;
- [Internal Delivery Desk #160](https://github.com/teamleaderleo/fieldwork/issues/160) — repairs, execution, composition, and closeout;
- [Priority-zero upstream backlog #435](https://github.com/teamleaderleo/fieldwork/issues/435) — complete numbered contribution inventory.

The issue bodies own live state. Pull requests, exact source heads, reviews, and workflow receipts linked from those issues own their narrower facts. This file is only a stable route to them.

A generated cockpit may later project current state under [issue #303](https://github.com/teamleaderleo/fieldwork/issues/303), but a generated view must remain reproducible from exact inputs and must not become authority.

No desk, queue, packet, or repository file authorizes merge, release, deployment, spending, private-data access, or public upstream contact. Those actions require their own explicit authority.
