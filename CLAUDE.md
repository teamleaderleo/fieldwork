# Claude Entry Point

`AGENTS.md` is the binding operating contract for this repository. Start with `START_HERE.md`, then load the assignment-specific material you actually need instead of treating this file as a second policy layer.

Use `REFERENCE_POLICY.md` before posting third-party GitHub references in issues, pull requests, comments, reviews, or discussions. Use `INTEGRATION_CONTEXT.md` before claiming broader use, operational consequence, or ecosystem impact.

A bounded one-worker playground experiment needs no upstream fork or Fieldwork issue. Wider claims still need evidence labels, primary sources, explicit limitations, and an integration-context dossier when applicable.

Upstream-contact authority is defined in `AGENTS.md`; this entry point adds no separate authorization rule.
