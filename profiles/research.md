# Research Profile

Kernel: [`KERNEL.md`](../KERNEL.md)

## Use this profile when

The assignment requires source reading, reconnaissance, a bounded experiment, prior-art research, a change thesis, or a retained negative result.

## Procedure

1. Identify the bounded question, claim scope, exact target revision or retrieval boundary, canonical records, and stop condition.
2. Search existing findings, issues, PRs, branches, experiments, testbeds, and active writer leases before creating work.
3. Read implementation, tests, call sites, configuration, generated boundaries, state ownership, side effects, failure paths, cleanup, and public contracts.
4. State competing hypotheses and the evidence that would distinguish them.
5. Form a bounded change thesis: current behavior, consequence, proposed improvement, evidence, and boundary.
6. Prefer a runnable probe, adversarial case, or realistic owned integration when it adds evidence.
7. Use recent issue and PR context as supplementary material, not as a substitute for source understanding or a menu of work.
8. Search primary precedent first and record both the supported principle and the important difference from the current case.
9. Preserve passing controls, negative results, disproved premises, alternative architectures, and uncertainty.
10. Promote to implementation, comparative evaluation, review, a retained finding, or a stop only when the evidence supports that transition.

## Claim boundaries

- A toy model supports a mechanism claim, not ecosystem impact.
- One owned integration supports an integration observation, not general adoption.
- A prepared target test is not an executed result.
- Source disjointness supports mechanical portability, not semantic currentness.
- A missing close precedent is a useful result when the search boundary is recorded.

## Outputs

Use one canonical finding for any retained conclusion, decision comparison, implementation candidate, or review state. Put parallel evidence in unique files. Keep issue comments to material routing events.

A research handoff must identify:

- exact source boundary;
- strongest supported finding;
- evidence level by claim;
- runnable evidence or explicit feasibility limit;
- ranked next directions or retained stop;
- uncertainty and reopening trigger;
- smallest next action.
