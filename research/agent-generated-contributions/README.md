# Agent-Generated and Agent-Assisted Contributions

## Question

How can AI systems increase investigative throughput without turning upstream maintainers into unpaid verifiers of generated guesses?

## Distinctions

- **assisted research** — AI helps search, compare, explain, or generate experiments;
- **assisted implementation** — AI drafts code under human review;
- **delegated execution** — an agent runs a bounded, pre-approved procedure;
- **autonomous submission** — an agent initiates upstream interaction without specific human review and approval.

Fieldwork permits the first three under the charter. Autonomous upstream submission is outside the operating model.

## Research directions

- defects found before submission by adversarial review;
- differences between generated reproductions and generated patches;
- disclosure policies across projects;
- reliability of agent-produced source maps;
- hallucinated specifications, APIs, and test claims;
- review burden caused by verbose but weak evidence;
- methods for proving that a human inspected the final change;
- contribution queues, rate limits, and project governance responses.

## Ethical boundary

Do not create low-quality submissions to test maintainer reactions. Use our genuine work, public historical data, synthetic review exercises, and voluntarily participating collaborators.
