# Gemini Entry Point

Read and follow `AGENTS.md` and `START_HERE.md` before taking action.

Use `EXPERIMENTS.md` and `playgrounds/` for bounded one-worker tests that require no upstream fork or Fieldwork issue. Record the question, command, environment, result, uncertainty, and disposition.

External GitHub issue, pull-request, discussion, and commit references must use `redirect.github.com`. No Fieldwork record or playground authorizes upstream contact without a specific user authorization.
