## Shared working rules

- One worker owns one lane path or testbed branch.
- Workers post claims before substantial work.
- External source stays read-only.
- Every external GitHub issue, pull request, discussion, and commit reference uses `redirect.github.com`.
- Prompts, credentials, private source, provider payloads, account identities, and production resources stay outside retained evidence.
- Ambiguous mutations stop further mutation until read-after-write reconciliation completes.
- Fresh-thread success or failure is recorded as a control, never assumed as a universal recovery.
