## In simple words

This campaign asked why an agent could use a capability earlier and later lose discovery, execution, result certainty, or accurate status. The answer is several independent lifecycle failures rather than one tool list going stale.

The completed campaign provides a privacy-safe receipt that identifies the earliest observable divergence and a promotion order for bounded repairs. Broad reconnaissance is closed.

## Final answer

A current capability can first diverge at:

- saved/current host reconciliation;
- logical-to-wire request serialization;
- global catalogue-to-binding capture;
- deferred exposure without discovery;
- required execution;
- completion-to-durable-result identity;
- display projection.

Fallback authority is a separate decision after required execution becomes absent.
