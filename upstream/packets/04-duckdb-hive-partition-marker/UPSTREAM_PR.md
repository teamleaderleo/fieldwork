## Human rewrite brief

### Suggested title

`fix(parquet): preserve literal Hive default-partition marker`

### Summary

- keep raw `__HIVE_DEFAULT_PARTITION__` reserved for SQL NULL partitions;
- URL-escape the exact literal marker so it receives a distinct directory;
- cover fixed filenames, UUID filenames, nested multi-column partitions, and raw-marker compatibility.

### Problem

Partitioned `COPY` currently emits the same directory segment for SQL NULL and the literal string `__HIVE_DEFAULT_PARTITION__`. With fixed output filenames, one partition can overwrite the other. With UUID filenames, both files can survive while both still read with SQL NULL partition semantics.

The governing rule is that distinct logical partition values receive distinct path identities.

### Change

After applying the existing Hive escape function to a non-NULL partition value, compare the result with the reserved raw marker. On equality, encode the first underscore as `%5F`. The existing Hive URL decoder restores the literal string during readback. Raw-marker behavior for SQL NULL remains unchanged.

### Tests

- native SQLLogic regression: `test/sql/copy/parquet/parquet_hive_default_collision.test`;
- fixed-name collision and row round trip;
- raw and encoded directory assertions;
- `{uuid}` filename control;
- nested `(region, p)` multi-column matrix;
- existing raw marker remains SQL NULL;
- ordinary project CI at the exact human-authored head.

### Compatibility

- public API: unchanged;
- existing behavior retained: raw marker remains SQL NULL;
- path behavior: one exact literal now uses `%5F_HIVE_DEFAULT_PARTITION__`;
- platform/runtime: existing URL path codec;
- performance/allocation: one exact string comparison per non-NULL partition segment and a small replacement only on equality;
- migration/rollback: encoded directories remain readable through current URL decoding; source hunk is independently reversible.

### Alternatives considered

- reader-only repair cannot recover overwritten path identity;
- UUID filenames preserve files while leaving partition semantics collapsed;
- rejecting the literal prevents silent collision but unnecessarily makes the value unrepresentable;
- configurable markers widen API and compatibility scope.
