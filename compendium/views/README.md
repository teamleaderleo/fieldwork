# Compendium views

These files are curated ways to enter the same underlying compendium entries. They are not separate truth stores.

- [`FANTASTIC_BUGS.md`](FANTASTIC_BUGS.md) — field-guide view over recurring bug species.
- [`GLOSSARY.md`](GLOSSARY.md) — concept definitions and domain-qualified meanings.
- [`IDENTITY_AND_AUTHORITY.md`](IDENTITY_AND_AUTHORITY.md) — identity, authority, generation, and publication relationships.
- [`COUNTEREXAMPLES.md`](COUNTEREXAMPLES.md) — cases that stop attractive rules from becoming universal.
- [`EVIDENCE_AND_GATES.md`](EVIDENCE_AND_GATES.md) — proof completeness, skipped discriminators, and broad-gate classification.
- [`CURATION_PLAYGROUND.md`](CURATION_PLAYGROUND.md) — several ways to browse, organize, challenge, and extend the corpus.
- [`LEARNING_PATHS.md`](LEARNING_PATHS.md) — optional self-directed routes through related systems/debugging ideas.

For a cold start, use [`../START_HERE.md`](../START_HERE.md).
